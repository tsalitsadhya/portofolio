E-Commerce Insight Dashboard

Developed an interactive E-Commerce Insight Dashboard in Google Looker Studio as part of the MySkill Mini Project. The dashboard provides a clear view of key performance indicators:

  • Top 5 products by profit
  • Sales trends by month
  • Profit by product category
  • Shipping mode composition

Enables decision-makers to monitor sales patterns, understand customer preferences, and optimize business strategies through data-driven insights.

Student Prediction

Developed a web-based student performance prediction system using machine learning. Built with Django, PostgreSQL, and a Random Forest classifier.

  • Graduation prediction with confidence scores
  • Learning style analysis and study partner recommendations
  • Interactive dashboards for students and instructors

Demonstrates how data-driven analytics can support students' academic success and help educators identify at-risk students early.

Shopping Analysis

Built a market basket analysis using the Apriori algorithm to uncover customer purchasing patterns and provide actionable recommendations.

  • Frequently bought item combinations identified (e.g., bottled beer & sausage)
  • Confidence scores and lift metrics calculated
  • Bundle promotion and cross-selling strategies recommended

Revenue Accounting System

Developed a web-based Revenue Accounting System to record and monitor daily retail transactions. Built with PHP and MySQL.

  • Create and manage invoices with itemized details
  • Automatically calculate total price, payment, and change
  • Generate daily transaction reports with sales recaps and profit
  • Export transaction details to PDF

Supermarket Analysis Dashboard

Designed an interactive SuperMarket Analysis Dashboard in Excel with slicers for dynamic filtering.

  • Sales and quantity by city and product line
  • Gross income and average income by payment method
  • Sales distribution by gender

Helps managers understand customer behavior, monitor performance, and make data-driven decisions.

e-LISA — Line Integrity & Sanitation Application

Developed during internship at PT. Bintang Toedjoe — A Kalbe Company. e-LISA is an enterprise web application designed to monitor and manage production line integrity and sanitation processes.

  • Secure authentication system with role-based access control
  • Real-time monitoring of production line sanitation status
  • Digital checklist and inspection report management
  • Audit trail and compliance tracking for hygiene standards

Built with React / Next.js, streamlining previously manual sanitation inspection workflows into a centralized digital platform.
